Every new UI surface for gating X analytics behind the shared X wallet, with the cost of each sync shown before you spend. Interact with the tweet-count selector and the balance scenarios to see the live cost behavior these screens are built around.

These are static mockups for the [Design] story, rendered as light screens because ContentStudio has no dark mode. Metering is dual-currency: new users pay dollars from the X wallet, legacy add-on users pay X credits (1 credit = $0.0166). Switch the cohort in the sync section to compare. Prices shown are the amount the user pays. The raw X cost and ContentStudio markup are never surfaced.

Per-sync cost modal

Story 5 · [FE] Live cost + balance gate

The core of the feature. Switch the cohort to see the same sync priced in dollars (new wallet users) or X credits (legacy add-on users). Change the tweet count to watch the price and button update live. Switch the balance scenario to see the funded, low, and no-billing-access states.

𝕏 Sync X (Twitter) analytics

X wallet balance $4.20
This sync will cost about $0.16 for 30 tweets
✓ Last sync charged $0.16

What is shown: a live estimate in the account's own currency that recalculates as the tweet count changes, the primary button reading the exact cost, an insufficient-balance state that swaps to a top-up CTA (Top up X wallet for dollars, Get more X credits for legacy) for billing users or an ask-admin message for everyone else, and the estimated-vs-actual reconciliation after a sync. Cohort is decided by WalletService::isEnabledForUser. Legacy credit cost is the same real cost converted at 1 credit = $0.0166. Blocking fires x_analytics_sync_blocked_insufficient_balance.

Scheduled sync settings

Story 6 · [FE] Projected cost + auto-pause

This is the existing X (Twitter) Data Sync Schedule modal with the cost projection added. Same fields, same options, same conditional behavior as today. Change the frequency to see the weekday and date-of-month fields appear, and Never to see the cost disappear.

X (Twitter) Data Sync Schedule ?

Each run costs about $0.16 for 30 tweets
About $0.16 per month at this schedule
If your X wallet runs low, scheduled runs pause and we will let you know. They start again automatically once you top up. Data you have already synced stays visible.

What is shown: the live modal's real options, Daily, Weekly, Monthly and Never, with the weekday picker on Weekly and the 1 to 30 date picker on Monthly, plus the eight tweet counts. Added for this feature: the per-run and per-month cost projection and the auto-pause promise. Choosing Never hides the tweet count and the cost, matching today's behavior. The primary button reads Create when no schedule exists yet and Update when one does. Pausing fires x_analytics_schedule_paused_insufficient_balance.
