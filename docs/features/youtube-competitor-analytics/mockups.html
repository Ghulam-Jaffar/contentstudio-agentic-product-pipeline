The YouTube tab of Competitor Analytics, drawn against the shipped Facebook and Instagram reports. Chrome, spacing, card treatment, and palette are taken from the running components rather than approximated — the same 240px analytics sidebar, the same sticky header card, the same rounded-xl white cards on the #F4F6FA canvas.

Syncing is free and carries no wallet, price, or confirmation step — unlike X, YouTube's API charges nothing per call. The limit is a daily quota, not money, so the sync button behaves exactly as it does on the Facebook and Instagram reports.
Every widget shown here is buildable from public YouTube Data API v3 fields. Nothing on this page depends on owner-only metrics — no watch time, no retention, no traffic sources, no demographics, no dislikes. Subscriber counts are rounded by the API to three significant figures for everyone except the channel owner, which the report discloses inline rather than burying in a help article.
