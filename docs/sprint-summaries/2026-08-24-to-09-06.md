It is also the exact gap the MCP authentication epic exists to close, so it belongs to that epic rather than floating in No Epic.

2. **The MCP epic came through with only its two submission stories.** The authored set was research, then implement user authorization, then submit. On the board there are just the two directory submissions (Claude and ChatGPT), split from what was one story. **The authorization work itself is not on the board** — and item 1 above is a live exploit against precisely that missing piece. Worth reconciling before either submission starts, since neither directory will review a connector without a working authorization flow.

Sequencing is worth confirming, since the API story assumes a competitor feature to expose and the two network efforts assume a shared reporting shape.
