## Epics

### Epic A — Public API publishing lifecycle: edit posts, approvals, account disconnect  `R`
Slug: `api-post-editing-approvals-account-disconnect`
Editing is currently blocked for unpublished posts via the public API. Allow editing any post that is not published / partially-published, across the full payload (content, media, scheduling, accounts, and the approvers / approval workflow), including multi-level approval. Also add account disconnect/removal (we already have connect).
Proposed stories:
1. `[BE]` Allow editing non-published posts via public API (block only published + partially-published); accept full editable payload
2. `[BE]` Support the multi-level approval workflow in the public API (set/replace approvers and stages, approve/reject)
3. `[BE]` Add public API endpoint to disconnect / remove a connected social account
4. `[BE]` Update the OpenAPI spec + guide and keep the agent `SKILL.md` in sync
5. `[CLI]` Add `posts:update` + approval editing + `accounts:disconnect`
6. `[MCP]` Add update-post, approval, and disconnect tools to `contentstudio-mcp`
7. `[Zapier]` Add/extend actions: update post, disconnect account
8. `[n8n]` Add/extend node operations: update post, disconnect account
9. `[Make]` Add/extend modules: update post, disconnect account
