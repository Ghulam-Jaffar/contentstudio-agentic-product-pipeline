# Automated migration agent: research artifact

A question-based interactive research artifact for the proposed automated migration agent. It preserves the complete product scope while separating explanations across six views:

1. Goal and customer value.
2. Thirteen data categories with automatic behavior, customer involvement, constraints and evidence.
3. Ten competitor connection routes, access requirements and unknowns.
4. AI planning plus reliable background execution, a six-stage process and explicitly illustrative normal/blocked examples.
5. New/extended implementation components, current code evidence and release-verification questions.
6. Source documentation, peer-reviewed HCI/multimedia-learning papers, industry guidance and detailed research downloads.

`dist/` is the buildless hosted version. `migration-report.html` embeds the scripts, styles, logos and downloads for a standalone copy. `.openai/hosting.json` retains the previously approved private Sites identity. No PDF is generated.

No customer account is connected and no actual migration is run. Interactive examples are labeled illustrations. Production source access, category completeness, migration rights, destination import guarantees and performance remain unverified.

Research records live under `docs/features/competitor-data-migration/`: `01-research.md`, `agent-architecture-research.md`, `automation-source-research.md`, and `readability-research.md`.

The design applies segmented explanations, descriptive question headings, nearby constraints, consistent comparison attributes and a distinction between documented, proposed and unverified claims. This is informed by research; it is not a claim that user comprehension has been validated. Standard text is 15px; an optional larger-text setting and browser resizing are supported. Actual ContentStudio/Hootsuite logos come from the mounted product/marketing assets.

Verification: browser checks passed for six views, thirteen data selections, ten sources and route filters, six process stages, two illustrative cases, evidence filtering, deep links and copy behavior, standard/larger/200% text, and widths 320–1440px. No JavaScript errors were observed. Screenshots of desktop and mobile views were inspected. Core ordinary text color pairs exceed 4.5:1 contrast; this check is not a complete accessibility certification.
