Why investigate Hootsuite REST and MCP?+

REST documents organization/profile/message reads. MCP is an interface through which an agent can call published Hootsuite tools. Perch, Nest, Lumen and Parliament expose different product capabilities.

Neither interface establishes complete bulk export. Enumerate permitted tools/endpoints, pagination, account entitlements and retention rights. A documentation MCP endpoint is different from an operational product connector.

Exports can help verify fidelity or fill supported gaps. For sources without a permitted automated extraction route, the honest offer is assisted migration until such a route exists.

What makes this reliable enough for bulk migration?+

Durable state

A database ledger records every source object, destination mapping, attempt and unresolved outcome. A chat transcript is not the execution record.

Safe retries

Source identifiers and destination idempotency/reconciliation prevent duplicate writes. A lost response must be resolved before repeating a write.

Restricted tools

Credentials and workspace scope come from authenticated server context. The model gets approved candidates and validated operations.

Untrusted source content

A caption saying “ignore instructions” remains post content. It must never become an instruction to the agent or grant it a new tool.

05 / IMPLEMENTATION DIRECTION

What must we build and prove?

ContentStudio already has useful account, content and agent infrastructure. A migration service still needs new durable state, safe import operations and source-specific validation.

Start with an automatic connector and a shared migration engine.

Keep the complete migration goal. Prove one connected source and representative relationships before expanding coverage.

Which existing code can the team reuse?+

Agent tools and authenticated workspace scope

Agno tool infrastructure, a ContentStudio HTTP client and server-injected credentials already exist. Normal chat writes use confirmation and are not a bulk-migration contract.

What should the first proof deliver?

QuestionEvidence to return
Can the source connect automatically?Authorized inventory and paginated reads, actual category coverage and resolved migration rights.
Does the data arrive correctly?Field, asset and relationship comparisons; every missing or transformed field reported.
Can it run safely without babysitting?Recovery after interruption, no duplicate objects, no unintended live actions, exceptions isolated.
Does it reduce customer work?Measured customer interventions, time to a verified setup and the remaining manual steps.
Can we operate it as a premium service?Source plan eligibility, ContentStudio quotas, retention obligations, throughput and actual API/model cost.

A paid plan does not remove source restrictions.

Check source/API entitlements and ContentStudio capacity before starting. Use AI on schemas and selected metadata; copy large media and post datasets through ordinary workers. Do not silently upgrade accounts or promise a price before measuring cost.

Any new migration API also needs planned coverage across the public REST API, CLI, MCP and applicable automation apps. This is research and implementation direction, not an approved PRD or story set.
